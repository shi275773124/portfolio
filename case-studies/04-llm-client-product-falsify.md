# 案例 4：自研直播复盘桌面端与可靠性工程（product-falsify）

## TL;DR

为解决直播间下播后「看数慢、听录屏慢、复盘流于形式」的痛点，独立开发了一款集成 LLM 的桌面端复盘工具（Rust Tauri + Web 前端，自动拉取罗盘分钟级数据与主播逐字稿生成诊断报告）；并为它构建了软件行为对抗测试体系 `product-falsify`（错误契约表 + NIST 2-way 32 例故障注入矩阵）。**首战全绿通过的同时，当场抓出并修复了一个严重线上隐患：API 402 额度耗尽被当成网络波动死循环重试 3 轮（白白浪费 12 次大模型调用），且界面还在误导运营点击「再试一次」。**

## 业务与产品背景

日常店播与大场下播后，运营和主播需要对齐「哪一分钟掉了在线、哪段话术没接住流量、哪个品讲崩了」。传统做法是人工对照罗盘曲线听回放，耗时极长。
因此我独立开发了这套**直播复盘桌面客户端**：
- 一键抓取当场直播罗盘分钟级流量/成交数据 + 自动转写直播逐字稿；
- 内置品牌商品知识库与复盘方法论提示词，自动生成带时间轴证据的复盘报告；
- 团队高频迭代（每周 1–2 个版本），配有 52 项基础编译与结构检查。

## 痛点：基础检查全绿，为什么外部新用户第一天还是卡死？

某次版本发布前，52 项常规代码检查全部通过，但一位**新入职运营（使用免费额度档、首次打开未登录罗盘、本地无缓存）**当天就在核心复盘第二步卡死。
复盘暴露出传统自测的四个盲区：
1. **异常分支平时测不到**：开发者自己测试时网络好、API 额度充足，超时/断网/欠费等失败分支从没被真正触发过；
2. **「作者机」不代表真实用户环境**：开发者电脑上永远是「已配置 Key + 已登录 + 缓存齐全」，恰恰漏掉了新用户的冷启动路径；
3. **拦截提示文案自相矛盾**：列表为空时，弹窗却提示用户「请先勾选采纳项」；
4. **报错后再恢复，界面残留旧状态**。

## 我做了什么

### 1. 建立客户端行为审计标准（`product-falsify` v0.1 → v0.8.0）

核心原则：**界面上的每一个按钮文案、状态徽标、报错提示都是一项「承诺」，测试时默认它会撒谎**。针对每个核心功能强制检验：空输入、断网、中途报错、失败后清场、连点防抖、重启恢复等边界场景。

### 2. 引入工业级故障注入与组合测试（v0.8.0）

参考微软 Chaos Engineering、AWS FIS 与 NIST 组合测试标准，落地三件套：

| 工程机制 | 解决什么问题 | 落地实现 |
|---|---|---|
| **8 类标准故障原语** | 模拟真实世界各种接口挂掉的样子 | 预置 `timeout`（超时）/ `hang`（假死）/ `reset`（断连）/ `402`（额度耗尽）/ `401`（鉴权失效）/ `badjson`（格式损坏）/ `refuse` / `partial`（流式截断） |
| **前后端错误契约表** | 防止后端改了一句中文报错，前端就认不出错误类型 | 12 类错误语义强绑定，机器校验「断路器规则 + 用户提示文案」两侧一致 |
| **NIST 2-way 组合矩阵（32 例）** | 用最少用例覆盖 90%+ 的多因素交叉 Bug | `用户身份（新用户/老用户）× 本地环境（冷启动/热缓存）× 8 类接口故障 = 32 例` 自动化跑批 |

每条用例必须同时通过 **5 项行为断言（G0 能启动 / G1 不崩溃 / G2 报错有明确出口 / G3 提示文案说人话且不撒谎 / G5 恢复后无脏状态残留）**。

### 3. 测试仪器：前端故障剧本注入桩（Test Rig）

自建自动化测试桩：保留真实前端渲染界面，通过浏览器模块映射（`importmap`）将桌面底层 API 与大模型接口替换为可编排的故障剧本队列，几秒钟内即可模拟完 32 种极端异常场景。**测试仪器自身也带冒烟自检**——首战即抓出修复代码自身的旧报错卡片残留问题。

### 4. 实战战果（32/32 跑通并拦截真实线上 Bug）

- **拦截 402 额度耗尽死循环重试 Bug**：当 API 返回 `402 Quota Exceeded`（余额不足）时，原本属于不可恢复错误（应立即停止并提示充值/切换 Key），却被底层误判为网络瞬时波动，自动重试满 3 轮（= 白白放大 12 次无效请求），且界面还显示「重试」按钮诱导用户继续点。修复后实现精准断路并直接引导切换通道。
- **根治「改一句中文文案就击穿断路器」的脆弱设计**：此前某版本后端把报错文案从“请求超时”润色为“模型接口超时了”，导致前端正则 `/timeout|没返回/` 匹配失效，断路器当场瘫痪。通过引入「错误码契约表」替代脆弱的中文文本匹配，彻底锁死此类事故。

## 可迁移价值

- **兼具一线业务体感与全栈交付能力**：因为自己天天在一线盯店播和复盘，所以极其清楚运营和主播在哪个界面动作上会卡住、哪句提示词是废话；
- **AI 产品的工程化落地能力**：不只是调通大模型 API 出个 Demo，而是能把异常处理、成本控制（防无效重试）和新用户体验打磨到生产可用级别。
